# Mission 1: Welcome to the Cloud

## Mission Overview
This mission serves as my onboarding process as a Junior Cloud Infrastructure Engineer Trainee. The goal is to set up my professional workspace, navigate a Linux environment, and establish a GitHub portfolio.

## Objectives
- Access a cloud-based Linux environment using KillerCoda.
- Gather basic system information and organize files.
- Create and maintain a professional GitHub repository.

## Activities Performed
1. Created a new Linux user account with sudo privileges.
2. Navigated the file system and extracted system hardware information.
3. Created directories and markdown documentation files using the terminal.
4. Set up my GitHub Cloud Computing Portfolio repository.

## Linux Commands Used
- `useradd`, `passwd`, `usermod`, `su` (User management)
- `whoami`, `pwd`, `hostname` (Environment checks)
- `cat`, `uname`, `lscpu`, `free`, `df` (System information)
- `mkdir`, `cd`, `nano` (File and directory operations)

## Skills Learned
I learned how to successfully provision a new user in Linux, extract critical system diagnostics, and properly use Markdown for professional cloud documentation.
