# Google Cloud Platform (GCP)
- **Brief Overview:** GCP is a suite of cloud computing services that runs on the same infrastructure that Google uses internally.
- **Global Infrastructure:** GCP divides its infrastructure into Regions and Zones connected by Google's high-speed global network.
- **Cloud Management Console:** Google Cloud Console.
- **Four Core Services:** Compute Engine (Compute), Cloud Storage (Storage), Cloud SQL (Database), Google Kubernetes Engine / GKE (Containers).
- **Three Advantages:** Industry-leading AI and Machine Learning tools, exceptional data analytics, and the best Kubernetes integration.
- **Typical Enterprise Use Cases:** Big Data analytics, AI/ML model training, and modern containerized applications.
