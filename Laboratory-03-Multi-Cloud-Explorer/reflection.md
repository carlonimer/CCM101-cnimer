# Mission Reflection

During this mission, the cloud platform that impressed me the most was Google Cloud Platform (GCP). Knowing that they built the technology behind Kubernetes and use the exact same infrastructure for Google Search makes their platform incredibly fascinating.

Despite their differences, AWS, Azure, and GCP share many similarities. They all operate on a pay-as-you-go model and offer the exact same core infrastructure services—Virtual Machines for compute, Object Storage for files, and managed SQL databases. The concepts remain the same; only the naming conventions change.

Acting as a Cloud Solutions Consultant taught me that business requirements heavily dictate platform selection. You don't just pick the most popular provider. If a company relies on Windows, Azure is logical. If they need heavy AI, GCP is best. Technology must always serve the business need first. 

Finally, by completing this mission, my GitHub Cloud Computing Portfolio has significantly improved. It now looks like a professional repository demonstrating real-world documentation and comparative analysis skills.
