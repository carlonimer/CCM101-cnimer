# Microsoft Azure
- **Brief Overview:** Azure is Microsoft's public cloud computing platform providing a broad range of cloud services.
- **Global Infrastructure:** Azure operates in multiple geographies around the world, offering enterprise-grade infrastructure.
- **Cloud Management Console:** Azure Portal.
- **Four Core Services:** Azure Virtual Machines (Compute), Azure Blob Storage (Storage), Azure SQL Database (Database), Azure Virtual Network (Networking).
- **Three Advantages:** Seamless integration with Microsoft products (Windows, Active Directory), strong hybrid cloud capabilities, and enterprise-grade security.
- **Typical Enterprise Use Cases:** Hybrid cloud deployments, enterprise applications using Active Directory, and Windows Server migrations.
